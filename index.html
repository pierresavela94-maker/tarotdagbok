Mörkermåne (1–2 dagar före nymåne)

Reningsritual & Rökelsevandring

Rening & Vila

Du behöver: Rökelse (vit salvia, palo santo eller cederträ), ett värmetåligt fat och ett mörkt eller vitt ljus.

  1. Öppna ett fönster på glänt så att gammal energi kan lämna rummet.
  2. Tänd ljuset och rökelsen. Gå lugnt från rum till rum och låt röken svepa längs hörn, dörröppningar och runt din tarotlek.
  3. Tänk tyst för dig själv: "Jag släpper taget om det som varit och gör plats för stillhet och nytt ljus."
  4. Avsluta med en kopp örtte och tidig vila utan skärmar.
Nymåne (0% belyst)

Intentionsbrev & Frösådd

Nystart

Du behöver: Papper, penna, ett ljus och gärna en kristall för nystart (t.ex. Månsten, Bergkristall eller Grön Aventurin).

  1. Tänd ett ljus och ta tre djupa andetag för att landa i nuet.
  2. Skriv ner 1–3 tydliga intentioner i nutid, som om de redan håller på att ske (t.ex. "Jag bjuder in lugn och kreativitet i min vardag").
  3. Vik ihop lappen, lägg kristallen ovanpå och låt den ligga på ditt nattduksbord eller altare fram till fullmåne.
  4. Dra ett tarotkort för att se vad som stöttar dina intentioner den här månaden.
Tilltagande måne (Mellan nymåne & fullmåne)

Kreativ fokus- & energiritual

Bygga kraft

Du behöver: En energigivande kristall (Citrin, Karneol eller Tigeröga) och din dagbok.

  1. Håll kristallen i din dominanta hand och blunda en stund.
  2. Föreställ dig ett varmt gyllene ljus som fyller dig med mod, glädje och handlingskraft.
  3. Skriv ner ett enda konkret steg du kan ta idag eller imorgon mot dina nymåneintentioner – och bär med dig kristallen i fickan under dagen.
Fullmåne (100% belyst)

Månvatten, Kristalladdning & Släppa-tag-lapp

Kulmen & Magi

Du behöver: Dina kristaller, en glasburk med kranvatten + lock, samt papper och en eldfast skål.

  1. Ladda kristaller & månvatten: Placera dina kristaller och en sluten glasburk med vatten på fönsterbrädan (eller utomhus) där månskenet når dem över natten. Vattnet kan sedan användas till att vattna växter, i badet eller till te.
  2. Släpp det som tynger: Skriv ner oro, tvivel eller gamla vanor på ett papper. Tacka dem för vad de lärt dig och elda upp lappen säkert i en eldfast skål (eller riv den i små bitar och släng).
  3. Fullmåneläggning: Gör en 3-kortsläggning i fliken Läggning för att få klarhet kring vad fullmånen vill visa dig.
Avtagande måne (Mellan fullmåne & nymåne)

Renande saltbad / fotbad & Tacksamhet

Återhämtning

Du behöver: Havssalt eller epsomsalt, eventuellt torkad lavendel eller rosmarin, samt en lugnande sten (Ametist eller Lepidolit) bredvid badet.

  1. Häll en näve havssalt i badkaret eller i en balja för ett varmt fotbad.
  2. När du sänker ner kroppen eller fötterna i vattnet, föreställ dig hur saltet drar ut all trötthet, stress och tunga tankar ur dig.
  3. Avsluta med att skriva ner tre saker från den senaste månaden som du känner tacksamhet över.

Kristallguide & Skötsel

Utforska kristallernas energier, hur du renar dem och hur du laddar dem med ny kraft.

Så renar du kristaller

  • Rökelse (Salvia / Palo Santo): För kristallen genom röken i ca 30 sekunder för att rensa bort tung energi.
  • Selenit eller Bergkristall: Lägg dina kristaller på en selenitplatta över natten – selenit renar andra stenar automatiskt.
  • Ljud (Klangskål): Ljudvibrationer rensar kristaller skonsamt utan slitage.
  • Obs om vatten: Många kristaller (t.ex. Selenit, Malakit, Pyrit, Lepidolit) löses upp eller tar skada av vatten!

Så laddar du upp dem

  • Månljus (Fullmåne): Lägg kristallerna på fönsterbrädan över natten. Passar alla kristaller och ger mjuk, intuitiv energi.
  • Solljus: Ger stark, aktiv energi – men bara korta stunder (lila/rosa stenar som Ametist & Rosenkvarts bleks i direkt sol).
  • Jordkontakt: Gräv ner stenen i en blomkruka eller i naturen i ett dygn för djup grundning.
  • Intention: Håll kristallen i handen, blunda och tänk tydligt på vad du vill att den ska hjälpa dig med.

Grunderna i praktisk magi

1. Rening & Fokus

Rena alltid glasburkar, ljus och kristaller med rökelse (t.ex. rosmarin eller salvia) innan du börjar, och grunda dig med tre djupa andetag.

2. Intention är nyckeln

Örter och stenar är verktyg som hjälper ditt fokus – det är din tydliga intention och känsla som väcker magin till liv.

3. Brandsäkerhet

Lämna aldrig brinnande ljus eller glödande örter obevakade, och använd alltid ett eldfast fat under ljusen.

Guide till Hekate

Vägskälens, facklornas och nycklarnas gudinna – utforska hennes historia, hur du börjar, ritualer och böner.

Antik grekisk titangudinna

Vem är Hekate?

Hekate (uttalas He-ka-te) är en uråldrig gudinna av titansläkt (dotter till Perses och Asteria). Redan i Hesiodos Theogonin (ca 700 f.Kr.) beskrivs hon som högt ärad av både Zeus och gudarna med makt över jorden, havet och stjärnhimlen.

Hon är trösklarnas, vägskälens, nattens, magins och intuitionens beskyddare – en vis vägledare som bär två facklor för att lysa upp mörkret när du står inför livsval eller skuggarbete.

Hennes viktigaste epitet (heliga titlar)

I antik tradition åkallade man Hekate med olika titlar beroende på vilken hjälp eller energi man sökte:

Kleidouchos – Nyckelbärerskan

Bär nycklarna till gränserna mellan världarna och hjälper dig låsa upp nya vägar och insikter.

Phosphoros – Ljusbärerskan

Håller sina facklor högt i mörkret för att visa vägen när du tvivlar eller känner dig vilsen.

Enodia – Vägskälens gudinna

Beskyddar resenärer och vägleder dig vid trevägskorsningar och avgörande livsbeslut.

Propylaia – Portens väktare

Vakar vid hemmets tröskel och ytterdörr för att hålla oönskad energi borta.

Soteira – Rädderskan

En beskyddande titel som används när man ber om trygghet, styrka och beskydd i svåra tider.

Kourotrophos – Barnens & de svagas beskyddare

Vakar över unga, utsatta, övergångar i livet och de som behöver moderlig omsorg.

Steg för steg för nybörjare

Så börjar du arbeta med & hedra Hekate

Du behöver varken bli "vald" genom dramatiska tecken eller köpa dyra saker för att börja. I hellenistisk tradition bygger relationen med gudarna på Kharis – ömsesidig respekt, tacksamhet och regelbunden närvaro.

1

Läs på och lär känna hennes historia

Börja med att förstå hennes antika rötter (t.ex. Hesiodos Theogonin, De homeriska hymnerna till Demeter och böcker som Keeping Her Keys av Cyndi Brannen eller Liminal Rites).

2

Tvätta händer & ansikte före ritual (Khernips)

I grekisk tradition tvättar man alltid händerna och ansiktet i rent vatten innan man närmar sig altaret, för att skölja bort vardagens damm och stress (miasma).

3

Skapa ett enkelt altare (helig plats)

En liten bricka, en fönsterbräda eller en hylla nära ytterdörren räcker utmärkt. Det viktigaste är att platsen hålls ren och vårdad.

4

Börja i det lilla med ljus, vatten & tarot

Tänd ett ljus, häll upp ett glas friskt vatten, presentera dig själv med egna ord och dra ett tarotkort (gärna läggningen Vägskälet) för att lyssna in hennes vägledning.

Vad passar på ett Hekate-altare?

Ljus & Färger

Svart (beskydd, natten, skuggarbete), Vitt (månljus, renhet, klarhet) och Rött (facklornas glöd, livskraft). Två ljus symboliserar hennes dubbla facklor.

Symboler & Föremål

Antika nycklar, en skål för libationer (vatten/honung), Hekates hjul (Strophalos), hund- eller ormsymboler och din tarotlek.

Kristaller

Svart Obsidian, Månsten, Labradorit, Svart Turmalin, Rökkvarts och Ametist.

Rökelse & Örter

Frankincense (olibanum), myrra, gråbo (mugwort), rosmarin, lavendel, lagerblad och cederträ.

Månatlig huvudritual • Vid mörkermåne

1. Hekates Deipnon ("Hekates kvällsvard")

Rening & Tacksamhet

I antikens Aten firades Deipnon den sista kvällen i månmånaden (mörkermånen). Syftet var att rena hemmet från månaden som gått och lämna en gåva till Hekate.

  1. Rensa ut: Sopa eller torka golvet i riktning mot ytterdörren för att symboliskt föra ut gammal energi och stagnation.
  2. Rena med rökelse: Tvätta händerna, tänd frankincense, myrra eller rosmarin och låt röken rena ditt altare och ytterdörren.
  3. Ställ fram gåvan: Häll upp rent vatten (libation) och lägg fram en liten offergåva (t.ex. honung, bröd, dadlar, fikon eller olivolja) på en skål på altaret.
  4. Avsluta med tystnad: Läs en bön, tacka för månaden som gått och töm ut vattnet i en blomkruka eller utomhus dagen efter.
När du står inför ett svårt val

2. Vägskälsritual med två ljus & tarot

Vägledning

Du behöver: Två ljus (symboliserar Hekates två facklor), en nyckel och din tarotlek.

  1. Placera de två ljusen framför dig med nyckeln och tarotkortleken emellan dem.
  2. Tänd ljusen ett i taget och kalla på Hekate Phosphoros och Enodia att lysa upp det som varit dolt för dig.
  3. Blanda korten medan du fokuserar på ditt vägval och gör tre-kortsläggningen Vägskälet i fliken Läggning.
  4. Skriv ner dina insikter i dagboken innan du släcker ljusen (släck gärna med ljussläckare eller genom att nypa lågan istället för att blåsa).
Hemmets tröskel • Vid nymåne eller vid behov

3. Tröskelbeskydd med Hekate Propylaia

Beskydd

Du behöver: En nyckel (kan hängas diskret vid hallen), en nypa havssalt och ett litet glas vatten med en kvist rosmarin.

  1. Stå vid insidan av ytterdörren med nyckeln i handen.
  2. Doppa fingrarna i rosmarinvattnet och rita en liten cirkel eller ett kors på insidan av dörrkarmen (eller stänk några droppar på tröskeln).
  3. Be Hekate Propylaia att vaka över tröskeln så att endast trygghet, kärlek och goda avsikter släpps in i hemmet.
Avtagande måne • Inre läkning

4. Skuggarbete med Svart Obsidian

Självinsikt

Du behöver: En bit Svart Obsidian (eller en mörk skål med vatten), ett svart ljus och papper & penna.

  1. Tänd det svarta ljuset i ett nedsläckt rum och håll obsidianen i handen.
  2. Fråga dig själv ärligt: "Vilken rädsla eller gammal vana håller mig tillbaka just nu?"
  3. Skriv ner allt som kommer upp utan att döma dig själv. Avsluta med att tända ett vitt ljus som symbol för att du ser ditt mörker och väljer att växa igenom det.

Vid ett vägskäl eller inför tarot

"Hekate Enodia och Kleidouchos, väktare av vägskälen och bärare av nycklarna, stå vid min sida när jag står inför val. Skärp min intuition och visa mig den dörr som leder mot styrka och klarhet."

Vid Deipnon (Mörkermåne)

"Mörka moder och ljusbärerska, ta emot denna enkla gåva av vatten och bröd i tacksamhet. Jag lämnar den gångna månadens tyngd vid din tröskel och kliver med lättare hjärta in i det nya."

Uppskattade offergåvor & viktig omtanke

  • På altaret inomhus: Rött vin (en klassisk antik libation till Hekate – gillar man inte alkohol går druvjuice, granatäpplejuice eller honungsvatten lika bra), rent kallt vatten, honung, olivolja, bröd, dadlar, fikon eller rökelse (myrra/frankincense).
  • Handlingar som hedrar Hekate: Hundar är Hekates heliga följeslagare – att skänka en gåva till ett hundhem, ta hand om djur, plocka skräp i naturen eller hjälpa någon i en utsatt situation räknas som mycket fina offerhandlingar.
  • Viktig säkerhetsregel utomhus: I antika texter nämns vitlök, lök och ägg som gåvor vid vägskäl. Om du lämnar gåvor utomhus idag – lämna aldrig vitlök, lök, choklad, russin eller skräp i naturen, eftersom det är giftigt för hundar och vilda djur. Häll istället ut rent vatten eller lägg blomblad utomhus, och ha matgåvor inomhus på altaret.

Steg-för-steg-guide

Så kopplar du ditt eget Google Kalkylark (ca 3 minuter)

Appen sparar redan allt automatiskt i din webbläsare, men om du vill ha en extra molnkopia i Google Drive kan du enkelt skapa ett eget kalkylark:

  1. Skapa ett nytt kalkylark: Gå till sheets.google.com (gärna på datorn) och skapa ett nytt tomt kalkylark. Döp det till t.ex. Min Tarotdagbok.
  2. Öppna Apps Script: Klicka på Tillägg i toppmenyn → Apps Script.
  3. Klistra in skriptkoden: Radera all text som redan står i kodrutan, klicka på knappen nedan för att kopiera koden och klistra in den i Apps Script. Tryck på disketten (Spara).
Kod.gs (Google Apps Script) 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var payload = JSON.parse(e.postData.contents);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["id", "date", "spreadType", "spreadTitle", "cards", "cardId", "cardName", "cardArcana", "cardSymbol", "isReversed", "userNotes", "afterNotes", "keywords", "meaningText"]);
  }

  if (payload.action === "get") {
    var data = sheet.getDataRange().getValues();
    var headers = data[0];
    var rows = [];
    for (var i = 1; i < data.length; i++) {
      var obj = {};
      for (var j = 0; j < headers.length; j++) {
        obj[headers[j]] = data[i][j];
      }
      rows.push(obj);
    }
    return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
  }

  if (payload.action === "add") {
    var item = payload.entry;
    sheet.appendRow([
      item.id, item.date, item.spreadType || "single", item.spreadTitle || "",
      JSON.stringify(item.cards || []), item.cardId, item.cardName, item.cardArcana,
      item.cardSymbol, item.isReversed, item.userNotes, item.afterNotes,
      item.keywords, item.meaningText
    ]);
    return ContentService.createTextOutput(JSON.stringify({ status: "ok" })).setMimeType(ContentService.MimeType.JSON);
  }

  if (payload.action === "delete") {
    var rowsData = sheet.getDataRange().getValues();
    for (var r = rowsData.length - 1; r >= 1; r--) {
      if (String(rowsData[r][0]) === String(payload.id)) {
        sheet.deleteRow(r + 1);
      }
    }
    return ContentService.createTextOutput(JSON.stringify({ status: "deleted" })).setMimeType(ContentService.MimeType.JSON);
  }
}
